# 越南賽馬 · Cờ Cá Ngựa

線上越南賽馬桌遊。可單人挑戰電腦、同一台裝置輪流玩，或開房間連線對戰。

## 規則（本專案採用的越南常見玩法）

- 2–4 人，每人 4 匹馬。
- 每次擲 **兩顆骰子**，點數分開走。
- 擲到 **6** 才能出廄，停在自己顏色旁邊最外側的出發格。
- 擲到 6 或對子可再擲，同一回合最多三輪。
- 前方有馬就不能跨越。要踢對手，必須骰到剛好走到牠的格子。
- 己方馬不能重疊或跨越；馬槽也不能越過或疊上自己的馬。
- 跑完一圈後進入 1–6 號馬槽，點數必須剛好。
- 先佔滿 **3、4、5、6** 號槽的人獲勝。

## 本機執行

```bash
npm install
npm test
npm run dev
```

瀏覽器開啟 http://localhost:5173 。前端由 Vite 代理到 `:3001` 的 Socket.IO 房間伺服器。

正式環境：

```bash
npm run build
npm start
```

預設服務 port 為 `3001`，可用 `PORT` 覆寫。
